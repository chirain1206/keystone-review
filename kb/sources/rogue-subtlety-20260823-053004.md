# 12.1敏锐贼大秘境/单体手法要点

## 爆发资源条件

- 【爆发资源条件】进影舞爆发需满足"标记一层"或"至黑在手"，且暗技层数≥5；怪多（10只以上）时尽量标记三层或两层再进，避免至黑打到增压目标。（适用：单体 / AOE）

## 至黑处理原则

- 【至黑处理原则】至黑在手时无脑打暗打强克后接至黑，不用纠结暗技层数是否满5；当前版本暗技层数容易溢出。（适用：通用）

## 影分身克隆体机制

- 【影分身克隆体机制】影分身后两段是克隆体攻击，克隆之后还多一个克隆体；克隆体攻击联动巅峰2产生1层暗影技巧，进影舞内再多1层——即舞内影分身立即给4层技巧，克隆影分身给6层技巧。（适用：通用）

## 平稳期观察

- 【平稳期观察】进入平稳期先观察下轮爆发CD（约8-10秒可抢一轮至黑循环，15秒以上大概率来不及），标记两层时就要开始规划，避免爆发前发呆或资源错乱。（适用：单体）

## 影舞内常规循环

- 【影舞内常规循环】影舞内遵循"一个攒豆技能+两个终结技"的节奏，见至黑在手就暗打强克后打出；影分身必须吃到括号（克隆）增伤（强克一次没出括号就得多强克一次，这两个技能必须吃上克隆）；至黑在手需要先消耗至黑（不然浪费绝命猎杀），否则消耗影分身。（适用：单体）

## 影舞内刀扇用法

- 【影舞内刀扇用法】进影舞前或影分身前来一发刀扇，因必爆可触发冷血提升下一发终结技10%暴击；刀扇基础伤害约24000，暗打平均约4万，但刀扇能吃到影舞结束后的增伤buff（50层时实际增伤约77%），故需穿插使用；至黑前不用必爆刀扇攒豆，会浪费冷血暴击加成。（适用：单体）

## 影舞结束增伤

- 【影舞结束增伤】影舞结束后获得的增伤buff可视为"暗刃"的复制（满层约77%增伤，30层约46%），能加成刺骨、黑火药、影分身二/三段、狗咬一段等魔法伤害。（适用：通用）

## 爆发后强克

- 【爆发后强克】影分身打出后满豆且有至黑在手时，需再用一次攒豆技能（暗打/背刺/狗咬）触发括号，再连续打两个终结技。（适用：单体）

## 技能轴：影舞爆发·满豆带括号·5技巧等一秒·标记1层

- 【新标记不触发掉层】分身 → 暗打 → 克隆至黑 → 刺骨 → 暗打 → 克隆刺骨 → 刺骨 → 暗打 → 克隆至黑 → 刺骨。（适用：单体；来源：视频内技能轴图）
- 【新标记触发掉层】分身 → 暗打 → 克隆至黑 → 刺骨 → 暗打 → 克隆刺骨 → 暗打 → 克隆至黑 → 刺骨。（适用：单体；来源：视频内技能轴图）

## 技能轴：影舞爆发·不满豆·5技巧等一秒·标记1层

- 【新标记不触发掉层】刀扇 → 分身 → 暗打 → 克隆至黑 → 刺骨 → 暗打 → 克隆刺骨 → 刺骨 → 暗打背刺 → 克隆至黑 → 刺骨。（适用：单体；来源：视频内技能轴图）
- 【新标记触发掉层】刀扇 → 分身 → 暗打 → 克隆至黑 → 刺骨 → 暗打 → 克隆刺骨 → 暗打 → 克隆至黑 → 刺骨。（适用：单体；来源：视频内技能轴图）

## 技能轴：影舞爆发·不满豆·5技巧等一秒·至黑在手

- 【新标记不触发掉层】刀扇 → 克隆至黑 → 暗打 → 分身 → 刺骨 → 暗打 → 克隆刺骨 → 暗打 → 克隆至黑 → 刺骨。（适用：单体；来源：视频内技能轴图）
- 【新标记触发掉层】刀扇 → 克隆至黑 → 暗打 → 分身 → 刺骨 → 暗打 → 克隆至黑→ 刺骨。（适用：单体；来源：视频内技能轴图）

## 技能轴：影舞爆发·不满豆·11技巧·至黑在手

- 【起手式】打1背刺满豆、2背刺强克，接着影舞至黑刺骨。（适用：单体；来源：视频内技能轴图）

## 技能轴：影舞爆发·满豆·12技巧·标记2层

- 【起手式】不取消括号，刺骨返豆接影舞刀扇强克影分身、再暗打强克至黑刺骨

## 平稳期抢至黑

- 【平稳期抢至黑】若下轮爆发CD大于10秒且标记一层，可抢一轮平稳期至黑循环；若不急着消耗标记（控标记），可以尽量让每个终结技吃到强克，溢出豆但不溢出能量。（适用：单体）

## 标记层数管理

- 【标记层数管理】标记一层时不打终结技，避免目标失去标记亏伤害；若需消耗标记，尽量在满豆且暗技层数足够时进行。（适用：单体）

## 暗技层数规划

- 【暗技层数规划】平稳期攒暗技约1秒1层，爆发前需保证暗技≥5且满豆；若来不及凑满豆+暗技5，宁可发呆存暗技也不要乱打攒豆技能。（适用：单体）

## 纯单体天赋

- 【纯单体天赋】点幽暗之刃+纠缠暗影，影舞内用背刺替代暗打（幽暗之刃吃影舞结束增伤），高纠缠期捅背刺；团本仅一个boss适用，较抽象但伤害最高。（适用：单体）

## 大秘境天赋

- 【大秘境天赋】放弃幽暗之刃点提升影舞内所有技能5%的天赋（含影分身、黑火药等AOE技能）；爆伤与攻速二选一，新手先用攻速，熟练后可试爆伤。（适用：AOE）

## 属性配装

- 【属性配装】单体因至黑必爆，暴击可降低，堆全能为主；AOE则偏重精通和暴击。（适用：通用）

## 45秒技能

- 【45秒技能】卡CD使用，最好与暗刃同开或暗刃前用；暗刃后太久不用不推荐，卡CD让一段伤害吃到增伤（约45000）。（适用：通用）

## 时间轴安排

- 【时间轴安排】大秘境时长的boss战不需要刻意留影舞单开影分身（比如笃定了boss收尾不交影舞），团本战斗3分钟的暗刃爆发前需要裸开一次影分身，但不要放在暗刃爆发前20秒那一波，不然会导致暗刃无法覆盖到上一轮纠缠暗影增伤（适用：通用）
