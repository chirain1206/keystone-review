# 12.1 敏锐贼 AOE 手法教学

## 至黑机制

- 【至黑机制】暗打或消耗印记会给目标上标记，通过5豆以上终结技消耗标记后获得至黑，使下一次刺骨必定暴击且伤害提升50%，并重新上标记。（适用：通用）

## 增压机制

- 【增压机制】开启暗影之舞后的前两次终结技会额外消耗连击点，伤害提升40%以上。（适用：通用）

## 克隆机制

- 【克隆机制】巅峰3效果：攒星技能后若暗影技巧层数大于5，下一次终结技会回豆并触发额外一次伤害（巅峰1）。（适用：通用）

## 英雄天赋消耗

- 【英雄天赋消耗】黑火药消耗印记层数时会触发一次AOE伤害，可弥补不打至黑的损失，因此即使黑火药伤害高于至黑也必须打至黑走循环。（适用：AOE）

## AOE爆发核心

- 【AOE爆发核心】进暗影之舞需带5层暗影技巧，保证影分身吃到克隆；至黑尽量不压进增压和克隆里，但拿到了就必须打，不能取消或改打黑火药。（适用：AOE）

## 怪少爆发手法

- 【怪少爆发手法】怪少时暗影技巧难存，最普遍手法是暗影之舞刀扇起手，利用舞内肉搏叠暗影技巧，两秒内必出克隆影分身。（适用：AOE）

## 怪多印记层数

- 【怪多印记层数】怪多时尽量以2-3层印记进暗影之舞，避免至黑出现在增压或克隆位置；1层印记进舞会导致至黑过早到手，被迫亏同归伤害。（适用：AOE）

## 爆发节奏

- 【爆发节奏】AOE战斗时间短，有暗影之舞配影分身就交，不用像单体一样控轴；45秒小爆发卡CD开，有暗影之舞就配合开，没暗影之舞裸开也要卡CD。（适用：AOE）

## 技能轴：暗影技巧3或4（等1秒）

- 【技能轴·3层标记没克隆】黑火药 → 刀扇 → 分身 → 黑火药 → 刀扇 → 至黑 → 黑火药 → 刀扇 → 黑火药 → 黑火药。（适用：AOE；来源：视频内技能轴图）
- 【技能轴·2层标记】黑火药 → 刀扇 → 分身 → 至黑 → 刀扇 → 黑火药 → 黑火药 → 刀扇 → 黑火药 → 至黑。（适用：AOE；来源：视频内技能轴图）
- 【技能轴·3层标记有克隆】分身 → 黑火药 → 刀扇 → 黑火药 → 至黑 → 刀扇 → 黑火药 → 黑火药 → 刀扇 → 黑火药 → 至黑。（适用：AOE；来源：视频内技能轴图）
- 【技能轴·2层标记有克隆】分身 → 黑火药 → 刀扇 → 至黑 → 黑火药 → 刀扇 → 黑火药 → 黑火药 → 刀扇 → 黑火药 → 至黑。（适用：AOE；来源：视频内技能轴图）

## 技能轴：暗影技巧5

- 【技能轴·暗影技巧5】刀扇 → 分身 → 刀扇 → 黑火药 → 刀扇 → 分身。（适用：AOE；来源：视频内技能轴图）

## 双目标手法

- 【双目标手法】双目标用刀扇攒豆、黑火药打终结技代替背刺刺骨；至黑伤害高，除至黑外不打刺骨；平稳期偶尔调轴打至黑，大部分时间留资源让至黑压进增压和克隆。（适用：双目标）

## 三目标手法

- 【三目标手法】三目标刀扇给3豆，配合暗影技巧可打无限终结技，印记消耗不固定，至黑随缘打，进爆发前存5层暗影技巧即可。（适用：AOE）

## 四目标以上

- 【四目标以上】黑火药伤害大于至黑，但仍需打至黑走英雄天赋循环触发AOE伤害；细节在于操控印记层数，避免至黑进增压和克隆。（适用：AOE）

## 至黑消耗

- 【至黑消耗】至黑到手不能长时间不消耗，AOE要卡CD消耗；单体手法不熟时宁可憋着也不能把至黑消耗在增压和克隆之外。

## 新技能狗咬

- 【新技能狗咬】伤害较高，属于攒豆技能但不给豆，适合在5层暗影技巧后触发克隆；跟暗刃一起开，暗刃后第一个攒豆技能用出最好；与暗影之舞联动仅10%伤害，手法上无固定要求。（适用：通用）
- 【狗咬效果】终结技在流血期间积累20%伤害，但目前有bug：伤害分摊、影分身二段伤害复制不了、不吃暗影伤害加成，实际效果偏弱；有暗刃的轮次配合开，没暗刃的轮次卡CD即可。（适用：通用）

## 插钥匙卡Buff

- 【插钥匙卡Buff】插钥匙前开暗影之舞拿增压豆，飞镖挂标记后消失，可卡满豆、两个增压、切割和暗刃结束后的暗影伤害提升30%buff；开门后10秒内用切割，可卡三个buff。（适用：通用）

## 聚怪前戏

- 【聚怪前戏】聚怪路上暗打上标记，有增压不打终结技；怪多刀扇能满豆可打终结技；聚怪久可裸开暗影之舞攒暗影技巧以及获得纠缠暗影，不消耗增压，让影分身吃到克隆和增压。（适用：AOE）
