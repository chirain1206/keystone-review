# 踏风武僧（风行者·天神）大秘境手法要点 — 至暗之夜 12.1

> 来源：B站 up 主 诗诗《12.1 踏风 PVE（天神）》视频提炼 + 用户专家整合笔记 + 社区《踏风速成指南》（多作者已互相沟通过、大方向一致；冲突处以用户整合笔记为准）。

## 核心机制

## 青龙之心三形态与叠加
- 小青龙：由风林组织机与升龙霸触发；套装青龙：释放乾元之巅后触发 4 秒；大青龙：天神御身（众神巨像）触发，效果为小青龙两倍。
- 任意青龙激活时急速提高 10%；大青龙不叠加为 20%。
- 大小青龙不能互相叠加，大青龙优先级高于小青龙；大/小青龙可分别与套装青龙叠加（如开风击后再开乾元，形成双青龙状态，急速与减 CD 效果叠加）。

## 怒雷破射程要点
- 怒雷破真实射程 6.5 码；在 8 码最大施法范围使用打不到怪，必须站近至 6.5 码内才能命中并吃满套装增伤。

## 乾元之巅与乾元镇踏（免费踏）
- 乾元镇踏是乾元之巅使用后自动释放的技能，乾元之巅持续时间内可使用两次（故称"免费踏"）。
- 天神御身读条期间可使用一次免费不占 GCD 的乾元镇踏。

## 天神御身使用前准备
- 进入天神前保证 ≥2 真气，确保第一时间打出怒雷与神鹤；真气不足先用猛虎掌补充。

## 天神御身打断抉择（爆发最难的点）
- 打断天神的技能取决于当前怒雷破 CD：
  - 怒雷没进 CD：必须先众神聚心再怒雷；
  - 怒雷 CD < 4 秒：直接幻灭踢 → 怒雷；
  - 4 秒 < 怒雷 CD < 6 秒：众神聚心 → 神鹤引项踢 → 怒雷；
  - 怒雷 CD ≥ 6 秒：直接旭日东升踢（最好天神前用幻灭踢再刷一次到 10 秒以下）。
- 天神读条是"一定要打断"的（伤害太低），除非利用天神移速干活。

## 天神打断机制分类
- 完全不打断读条：打断、扫堂腿、业报、壮胆酒、平心之环、驱散、翔龙在天等瞬发非伤害技能，以及乾元镇踏；
- 打断读条并立即触发青龙：猛虎掌、幻灭踢、旭日东升踢；
- 打断读条但不立即触发青龙：怒雷破、自断、神鹤引项踢（含瞬发）、活血、闪电等读条技能；
- 额外技能：规则各不相同，一般不打断读条。

## 总则（铁律，按优先级）

1. 乾元绝对不能开在白虎的 GCD 里，会导致整个爆发连锁崩盘；不要做任何所谓"爆发宏"。
2. 爆发分双乾元白虎与单乾元白虎，排序 2112 或 212（2112 药水节奏更好）；除白虎爆发外一般不开乾元。
3. 怒雷破后接什么：**纯单体环境接疾风踢（有疾风踢时）**；其余所有环境接神鹤引项踢。
4. 旭日东升踢使用规则：**纯单体与嗜血环境卡 CD 踢**（旭日峥嵘 + 雪怒战甲使其豆转伤害效率高于神鹤；注意套装 buff 吃不到旭日上；其优先级低于"天神打断技能抉择"）；2+ 目标只踢升龙扳机。
5. 下套爆发的天神转好时间取决于本爆发天神的开启时间；若出现重大操作失误，本爆发直接不打天神。
6. 进单乾元白虎前必须把触发的疾风踢打掉。
7. 白虎 CD < 19 秒不再打升龙霸；白虎 CD < 8 秒不再打怒雷破。
8. 平稳期把疾风踢尽量留到升龙后的小青龙里。
9. 天神御身读条期间可使用一次免费不占 GCD 的乾元镇踏。
10. 最大化卡 CD 升龙：当前升龙 CD <（旭日 CD − 普通怒雷读条时间 8−3.2=4.8 秒）时直接旭日，且升龙前不再打幻灭踢（升龙好了百分百直接用）；因为怒雷后需接神鹤，怒雷后旭日再升龙要等太多 GCD。
11. 升龙 CD < 10 秒时观察旭日与怒雷 CD 防卡升龙；必要时等升龙自然转好（旭日 CD 可浪费）。

## 爆发手法

## 单体/2 目标爆发起手
- 4 豆起手 → 白虎下凡 →（等白虎 GCD 结束）饰品+药水+乾元+怒雷破（可做宏绑定）→ 神鹤引项踢（消耗套装）→ 旭日东升踢 → 升龙霸。

## 单体输出优先级
1. 怒雷破（第一优先级）；
2. 疾风踢 > 神鹤引项踢（消耗套装；2 目标起只用神鹤消耗）；
3. 疾风踢、旭日东升踢（旭日减怒雷 CD）；
4. 赤精之舞、神鹤引项踢；
5. 幻灭踢；
6. 猛虎掌；
7. 真气 ≥ 5 且无其他技能可打时：白板神鹤引项踢。
- 【后期补充】除非真气/能量溢出，否则不打白板神鹤。

## 3 目标爆发（按旭日暴击次数分三档，均为 4 豆启动）
- 旭日 0 爆：白虎 → 乾元 → 怒雷 → 神鹤 → 旭日 → 升龙 → 神鹤 → 幻灭 → 怒雷 → 神鹤 → 乾元镇踏 → 神鹤 → 乾元镇踏 → 天神御身 → 神鹤 → 幻灭 → 怒雷。乾元内 5 神鹤；3 怒雷打不进乾元（极限 1 点能打 1 跳进乾元）。
- 旭日 1 爆：白虎 → 乾元 → 怒雷 → 神鹤 → 旭日 → 升龙 → 神鹤 → 怒雷 → 神鹤 → 乾元镇踏 → 神鹤 → 乾元镇踏 → 天神御身 → 神鹤 → 幻灭 → 怒雷。乾元内 5 神鹤；3 怒雷一半进乾元。
- 旭日 2 爆：白虎 → 乾元 → 怒雷 → 神鹤 → 旭日 → 升龙 → 神鹤 → 乾元镇踏 → 神鹤 → 乾元镇踏 → 神鹤 → 天神御身 → 众神聚心 → 神鹤。乾元内 4.5 神鹤（最后套装神鹤打一半≈1 白板神鹤）；3 怒雷吃满乾元；大青龙第一个 GCD 打怒雷，基本稳定 2 怒雷。

## 4+ 目标爆发（三档）
- 旭日 0 爆（少见）：白虎 → 乾元 → 怒雷 → 神鹤 → 旭日 → 升龙 → 神鹤 → 幻灭 → 怒雷 → 神鹤 → 乾元镇踏 ×3 → 神鹤 → 神鹤 → 天神御身 → 幻灭 → 神鹤。乾元内 4 神鹤，3 怒雷打一半进乾元。
- 旭日 1 爆：白虎 → 乾元 → 怒雷 → 神鹤 → 旭日 → 升龙 → 神鹤 → 怒雷 → 神鹤 → 乾元镇踏 → 神鹤 → 乾元镇踏 → 神鹤 → 天神御身 → 幻灭 → 神鹤。乾元内 4.5 神鹤。
- 旭日 2 爆：白虎 → 乾元 → 怒雷 → 神鹤 → 旭日 → 升龙 → 神鹤 → 乾元镇踏 → 神鹤 → 乾元镇踏 → 神鹤 → 天神御身 → 众神聚心 → 怒雷 → 神鹤。乾元内 5 神鹤；稳定追大青龙 2 怒雷。
- 暴击构成：面板 36% + 白虎双倍 4% + 天火踢 20% + 虎眼酒 20% + 雪怒战甲 20% = 100%（5 目标旭日一般能满爆）。

## AOE 嗜血期最优序列（默认五目标，期望 7 怒雷 + 9 神鹤，完成率 90%+）
- 白虎 → 饰品乾元怒雷 → 神鹤 → 旭日 → 怒雷 → 升龙 → 神鹤 → 乾元镇踏 → 神鹤 → 怒雷 → 神鹤 → 乾元镇踏 → 天神御身 → 聚心神鹤 → 怒雷 → 神鹤 → 乾元怒雷 → 旭日 → 怒雷 → 升龙 → 神鹤 → 乾元镇踏 → 神鹤 → 乾元镇踏 → 怒雷 → 神鹤。
- 注意：第二个升龙很难按出来（需手速，最好提前按入序列）；爆发打完乾元还有 5 个 GCD，可看触发打 8 怒雷或打到 11 神鹤；巨魔手法（8 怒雷 + 10 神鹤 + 多一个套装神鹤，30 秒 AOE 提升约 5%）仍在验证。

## 非嗜血单乾元爆发（期望乾元内 3 个完整青龙怒雷；旭日双爆 + 一次额外赤精才能 4 怒雷）
- 进白虎前身上不要带疾风踢。
- 起手：白虎 → 饰品乾元怒雷 → 神鹤 → 旭日，然后进入判定：
  - 旭日没双爆：升龙 → 神鹤 → 怒雷 → 神鹤 → 乾元镇踏 → 神鹤 → 乾元镇踏 → 天神御身 → 幻灭 → 怒雷 → 神鹤（乾元覆盖到这个怒雷与神鹤一半）→ 猛虎（触发疾风踢）→ 神鹤 →（青龙内可再打怒雷，否则不行）。
  - 旭日双爆：怒雷 → 升龙 → 神鹤 → 乾元镇踏 → 神鹤 → 乾元镇踏 → 神鹤 → 天神御身 → 聚心怒雷 → 神鹤（此神鹤也能享受乾元）→ 猛虎（疾风踢）→ 神鹤 → 怒雷（能完整打进青龙）。

## 双乾元爆发（期望乾元内 5 个完整青龙怒雷 + 1 个打不满的青龙怒雷）
- 进白虎前身上不要带疾风踢。
- 最优序列：白虎 → 饰品乾元怒雷 → 神鹤 → 旭日 → 升龙 → 神鹤 → 怒雷 → 神鹤 → 乾元镇踏 → 神鹤 → 乾元镇踏 → 天神御身 → 幻灭 → 怒雷（乾元覆盖到这个怒雷）→ 神鹤 → 幻灭（或疾风踢）→ 神鹤 → 乾元怒雷 → 神鹤 → 乾元镇踏 → 旭日 → 升龙 → 神鹤 →（后续看触发，加入高亮幻灭）。
- 双乾元上限 6 青龙怒雷 + 1 非青龙怒雷，下限 5 青龙怒雷 + 1 非青龙怒雷；第二个旭日若刷了怒雷，把 2 升龙里的"神鹤 乾元镇踏 神鹤"改成"神鹤 幻灭 神鹤"即可完成 6 青龙怒雷。

## 平稳期与时间轴

## 单体平稳期
- 尽量卡 CD 升龙霸；围绕怒雷破、套装神鹤/疾风踢、旭日东升踢循环；免费神鹤/幻灭回气，利用免费技能存高位真气（平时 5-6 点）。
- 最大利用旭日刷怒雷，且保证套装一定接神鹤——单体打高的关键。
- 白虎 CD < 19 秒停止升龙；升龙 CD < 7 秒即可开白虎。
- 升龙数量规划：理论上 2 个白虎之间可以打 4 个升龙，但实战很难达成；若出现失误，退而求其次追求 3 升龙。**绝不要为了卡 CD 升龙导致乾元内升龙与天神 CD 同时转好**（大青龙与小青龙不叠加，会损失青龙收益）。

## AOE 平稳期（2+ 目标）
- 神鹤引项踢转就完了；套装只用神鹤消耗；尽量保持高位真气（1+1 手法，保证高亮资源不溢出）。
- 高位真气进升龙且能立刻怒雷时，可赌 2 怒雷：升龙 → 怒雷 → 神鹤 → 幻灭 → 疾风踢 → 旭日 → 怒雷（脸好有脸黑无）。
- 旭日使用时机（升龙扳机）：升龙剩 7~8 秒提前打掉；或升龙剩最后一秒打完旭日直接升龙。
- 免费幻灭提前用掉，旭日后别用，防止刷好旭日 CD 卡升龙。
- 进爆发前把存的疾风踢用掉防止卡升龙（仅 AOE 需要）。

## 乾元安排与爆发循环节奏
- 起手 2 乾元可与大青龙后的 2 怒雷一起开吃双青龙；AOE 天赋（灵魂专注）打单体时起手白虎+乾元，2 乾元自行安排。
- 1 分半：开 2 白虎 + 单乾元；3 分钟：3 白虎 + 单乾元；4 分半：4 白虎 + 单乾元；211 循环。
- 进阶节奏：升龙 CD 25.5 秒、乾元小青龙 4 秒、大青龙 9 秒 → 单乾元爆发到下次爆发间隔可打 4 次升龙（90+4+9）/25.5=4。利用前置旭日技巧（怒雷读条原因每升龙延迟 1-3 秒）：单乾元后下个爆发按 98 秒 CD 算、双乾元后按 95 秒算。整体循环：起手双乾元 → 95 秒后单乾元 → 98 秒后单乾元 → 95 秒后回双乾元。熟练度越高爆发间隔越短；熟练度很低时，"绝食不打升龙等爆发"与"前置天神爆发"二选一。

## 天赋与配装

## AOE 天赋要点
- 必点两豆怒雷（疯狂神鹤需要真气支持）；三豆怒雷每两怒雷少一个神鹤，点三豆亏 2.4 个怒雷伤害；不点选中之节与宇宙能量（总计提升仅 2%）。

## 属性与装备
- 面板堆 36% 暴击、25% 急速，其余全精通，不要全能；算面板时手动取消心怀四方 buff 与朱鹤式（白虎、全牛式、金融式保留）。
- 武器先用双手（可升级）；饰品：团本尾王一分半饰品或高装等水壶，迷集盒当 3 分钟饰品用。
