# 想法验证：WoW M+ AI 复盘教练（暂名）

> 阶段 1（想法验证）产出 · 依据三份调研归档：market-and-demand-research.md / competitor-research.md / feasibility-research.md

## 一句话

给魔兽世界想进步的中高端大秘境玩家的"AI 复盘教练"：玩家上传自己的战斗记录 log，AI 对比顶尖玩家的打法，用自然语言告诉他"哪里可以打得更好、为什么"；玩家还能直接提问，AI 结合 log 上下文回答——并且 AI 能理解**战术意图**（例：5 分 36 秒喝爆发药没开爆发，是为了对齐 5 分钟后 BOSS 易伤阶段的 CD，不是失误）。

## 给谁用 / 解决什么

- **目标用户**：想进步的中高端玩家（打中高层大秘境、卡分数/进度、愿意为提升付费的人群）。首发聚焦国服中文用户（国服占全球活跃 44%）。
- **核心痛点**：玩家手里有 log、有视频，但"看懂 log → 翻译成该怎么改"这一步没人帮；现有工具只给数据、给排名、给"对错判定"，不解释"战术意图"，更不会回答问题。
- **用户价值故事**：作为卡在 15 层的大秘境玩家，我想要把我的 log 交给一个懂战术的 AI 教练，以便知道下一步具体练什么、为什么这么练。

## 调研结论

### 市场：✅ 需求真实、盘子够大、付费习惯已验证
- 国服活跃玩家超百万、居世界第一；10 层以上通关率 96%+，中高端是主流而非小众。
- 玩家现有提升路径：攻略/视频、看 log 工具、真人教练（Metafy）、代练陪玩（国服明码标价）——三条付费路径都已验证"提升"是愿意花钱的事。
- 高端社区已在用"剧本/对齐 CD"的语言讨论打法，与产品"理解战术意图"的定位高度吻合。
- 风险：赛季周期波动强（版本末期 M+ 参与度下滑明显）。

### 竞品：⚠️ 组合空白真实存在，但形态必须调整
- **没有任何工具同时做到"理解战术意图的分析 + 对 log/视频的自然语言问答"**。
- 最接近的 WoWAnalyzer：规则 checklist、团本为主、M+ 弱、无问答无视频；Archon App 做了"录像+log 同步回放"但只是回放不是分析；国服官方"AI 战报"是模板化报告，非对话式。
- 玩家已在手动用 DeepSeek 分析 WCL 数据——需求真实、无成熟产品。
- 三大威胁：WCL/Archon 正在平台化扩张；暴雪官方推"一键循环"碾压"教按键"类工具；国服官方做 AI 战报。**差异化窗口期有限。**

### 可行性：✅ 有条件可行，成本近零，成败点在 AI 分析质量
- 数据：玩家 /combatlog 生成的原生日志格式公开、开源解析器现成，零成本零配额，可绕开 WCL API 限流；WCL 公开 GraphQL API 可作增强。
- 视频同步：Warcraft Recorder（GPL v2）为每段视频生成 JSON 元数据（challengeModeTimeline：日志时间 ↔ 视频内时间），第三方直接读取即可对齐，无需改其代码。
- AI 成本：单次复盘分析约 1–2 美分，月 1000 次约 $15–50；部署用 Cloudflare + Supabase 免费层可做到基础设施 $0/月。
- 合规：暴雪政策下，**卖"自己的 AI 分析/教练服务"可收费，卖游戏内容/视频受限**；需加"非暴雪官方"免责声明，收费前律师确认一次。

## MVP 范围初判

**做（Must）：**
1. 玩家上传大秘境 log（原生 WoWCombatLog.txt，或粘贴 WCL 报告链接）；
2. AI 结构化解析 log → 生成个人复盘报告（关键时机、资源利用、与顶尖玩家打法对比）；
3. **战术意图理解**：区分"看起来异常但其实是高手操作"与"真失误"，并解释为什么；
4. 自然语言问答：针对该场 log 提问，AI 结合上下文回答（笼统问题也支持）。

**不做（Won't，本阶段明确排除）：**
- 不做录屏工具（Archon App 官方已做）；不做模拟/配装（Raidbots 垄断）；不做排名/分数（WCL、Raider.IO 垄断）；不做实时"按什么键"提示（暴雪官方一键循环碾压）。
- 不做视频上传分析（存储带宽贵）；视频时间轴同步定位放第二版（利用 Warcraft Recorder 元数据）。

**差异化锚点**：Warcraft Logs 数据之上的 **AI 教练解释层**——先 log 后视频。

**商业模式初判**：免费（基础 log 复盘）→ 订阅（AI 深度复盘/追问，对标 WCL Premium 约 $5–6/月级）→ 高价一次性战术咨询。收费点必须落在"AI 分析服务"上。

## 裁决

**⚠️ 调整后做。**

方向成立（市场大、需求真、空白明确、技术可行、成本近零），但按以下 4 条调整后再开工：

1. **定位调整**：不做"又一个 log 分析器/录屏器/模拟器"，做"WCL 数据之上的 AI 教练解释层"；
2. **聚焦**：只做大秘境、首发国服中文；
3. **MVP 收缩**：只做 log 复盘 + 问答（战术意图理解是命根子），视频同步第二版再说；
4. **合规红线**：卖分析服务、不卖游戏内容；定位"自己进步"，远离代练陪玩灰色地带。
