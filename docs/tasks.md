# 任务清单：WoW M+ AI 复盘教练

> 阶段 3（技术设计）产出 · 依据 docs/TECH-DESIGN.md
> 每个任务 ≈ 一次开发回合（一次 PR）粒度，带验收标准与依赖。QA 阶段将逐条对照 FR-x 验收。

## 分批计划

- **批次 1（地基）**：T1–T4
- **批次 2（核心闭环）**：T5–T7
- **批次 3（数据接入与防护）**：T8–T9
- **批次 4（外围与收尾）**：T10–T13

| # | 任务 | 验收标准 | 依赖 |
|---|---|---|---|
| T1 | 项目脚手架：Next.js(App Router)+TS 仓库、Supabase 项目创建、Vercel 项目关联与首次部署、环境变量管理、/api/health | 仓库 build 通过；Vercel 部署成功；/api/health 返回 ok；本地与线上环境变量隔离可用 | — |
| T2 | 数据模型与 RLS：建表（profiles/reports/processed_logs/report_chapters/conversations/messages/shares）+ 迁移脚本 + RLS 策略 | 迁移可重复执行；RLS 生效：用户 A 无法读写用户 B 的任何行；删除 report 级联删除章节/问答/分享 | T1 |
| T3 | 账号体系（FR-7）：Supabase passwordless 邮箱验证码 + Resend SMTP、登录/登出、未登录引导、验证码频控（错 5 次锁 10 分钟） | FR-7 验收标准逐条通过；验证码邮件送达（Resend 日志可见） | T2 |
| T4 | 浏览器端日志解析器 + FR-10 预处理：Web Worker 分块读取 WoWCombatLog.txt，识别大秘境战斗分段，按关键事件白名单提取（技能/爆发/CD/打断/死亡/增益减益/易伤/移动），产出结构化 JSON | 用样例文件（≥3 个真实 log，含噪声）测试：正确列出战斗（副本/层数/时间/专精）；结构化数据 ≤50K token/场且相对原始缩减 ≥90%；时间戳与原始一致；非日志文件明确报错（FR-2、FR-10 验收标准） | T1 |
| T5 | 复盘生成管线（FR-4）：6 章并行流式生成接口（SSE）、每章独立存储与幂等、断点重试（单章接口）、每章输出封顶 1800 token、章节级数据切片 + DeepSeek 上下文缓存、进度回传 | FR-4 验收标准通过：报告 p95 ≤120s；章节失败可单独重试；每场复盘的 token 用量与成本可观测（日志字段） | T2, T4 |
| T6 | 战术意图识别专项（FR-5）：意图判断提示词（先查战术合理性再下结论）、报告第 5 章实现、样例集构造（≥10 个"看似失误实为正确决策"案例 + ≥5 个真实失误案例）与评测脚本 | 开发自测：构造样例 ≥2 个通过；样例集文件与评测脚本就绪（QA 阶段跑 ≥80% 通过率） | T5 |
| T7 | 对话问答（FR-6）：问答流式接口、上下文组装（结构化事件切片+历史轮次）、10 轮上限、违规问题拒绝（代练/RMT 等）、"通用建议非本场数据"标注 | FR-6 验收标准逐条通过 | T5 |
| T8 | WCL 链接接入（FR-1/FR-3）：WCL v2 API client、链接校验与元数据拉取（副本/层数/角色专精）、对比链接基准数据、失败降级（提示改用文件/不含对比章节） | FR-1 验收标准通过（含全球服/国服链接）；FR-3 对比部分通过；WCL 配额耗尽时优雅降级不阻塞复盘 | T2, T4 |
| T9 | 额度与防滥用（FR-7 额度部分）：每账号每日 3 次复盘计数（按用户时区自然日）、用尽提示、Turnstile 人机验证接入（登录/创建报告接口）、IP/邮箱频控 | 同账号同日第 4 次被拒且提示准确；换时区边界正确；绕过人机验证的脚本请求被拒 | T3, T5 |
| T10 | 历史记录（FR-8）：列表/详情接口与页面、删除（级联） | FR-8 验收标准逐条通过；用户 A 无法访问用户 B 数据（接口层测试） | T3, T5 |
| T11 | 一键分享（FR-9）：shares 表 + 128-bit 随机 token、公开只读分享页 GET /s/:token、开启/关闭 | FR-9 验收标准逐条通过；token 不可枚举（随机性测试）；分享页无任何写操作接口 | T5 |
| T12 | 前端界面整合：首页（粘贴链接/选文件）、战斗选择页、报告页（章节进度+渲染+问答框）、我的复盘页、登录页、分享页、隐私政策/用户协议/免责声明页；响应式适配 | 全部页面可用、首屏 ≤3s、移动端自适应；报告页章节进度与重试交互正确 | T3, T5, T7, T10, T11 |
| T13 | 安全与合规加固：HTTPS、接口鉴权与数据隔离复核、上传数据结构校验（≤50K token 预算服务端再校验）、隐私政策/免责声明文案（"非暴雪官方产品，与暴雪娱乐无关"）、错误提示全覆盖 | 非功能需求（安全/隐私/合规）检查表逐项通过；未登录访问受保护接口一律 401 | T2, T3, T11 |
