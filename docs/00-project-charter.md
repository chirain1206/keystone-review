## 想法原文（用户原话转述）

开发一个辅助魔兽世界高端 PvE 玩家进步的工具（软件/网页）：

1. 用户上传游玩 log（大秘境、团本 BOSS）；
2. 工具辅助对比顶尖玩家的 log，或结合用户上传的实战视频，给出**手法提升意见**；
3. 用户可以针对视频、log，或笼统地提出问题，工具**分析并回答**；
4. 参考 Warcraft Recorder：录制的视频与 log 时间轴可对应（视频帧 ↔ 战斗事件）；
5. 关键特色：理解**战术意图**。示例：玩家 5 分 36 秒喝了爆发药但没开爆发——这不是失误，而是为了确保 5 分钟后 BOSS 进入易伤阶段时爆发药 CD 已转好。
