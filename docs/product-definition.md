# 产品定义：WoW M+ AI 复盘教练（暂名）

> 阶段 2（产品定义）产出 · 依据 docs/idea-validation.md 的裁决（⚠️ 调整后做）

## 一句话定位

为**想进步的中高端大秘境玩家**解决**"看不懂自己的 log、不知道下一步怎么练"**问题的 **AI 复盘教练**（网页工具）。

## 核心场景（用户什么时候用它）

1. **打完复盘**：打完一场大秘境（可能刚散队或刚限时），玩家把 log 传上来，几分钟内拿到一份复盘报告：这局哪里打得好、哪里可以更好、和顶尖玩家的差距、下一步练什么。
2. **带着疑问来问**：玩家对某场战斗有具体疑问（"我这波爆发开得对吗？""这个打断分配合理吗？"），直接问 AI，AI 结合 log 上下文回答。
3. **笼统求方向**：玩家卡分求方向（"我想上 3000 分，还差什么？"），AI 结合他的 log 给出方向性建议。

## MVP 范围（第一版）

### 做（In，已确认）

> 幕后能力（用户特别强调）：所有 log 在交给 AI 前必须**先预处理降噪**——剔除无用数据、提取关键事件，像 Warcraft Logs 那样整理成精简数据，既保质量又省 AI 成本。对应 PRD FR-10。

| 编号 | 功能 | 大白话 |
| --- | --- | --- |
| F1 | 上传 log | 粘贴 Warcraft Logs 报告链接（优先路径），或上传游戏原生战斗记录文件 |
| F2 | AI 复盘报告 | 生成结构化报告：关键指标、爆发/减伤/打断/移动等时机分析、哪里可以更好 |
| F3 | 对比顶尖玩家 | 用户自己粘贴顶尖玩家的 log 链接作为对比对象（系统自动抓样本放第二版） |
| F4 | 战术意图理解 | 区分"看起来异常但其实是高手操作"和"真失误"，并解释为什么（产品的命根子） |
| F5 | 对话问答 | 针对该场 log 提问，AI 结合上下文回答（第一版只针对当前这场） |
| F6 | 账号与历史 | 邮箱注册/登录，保存历史 log 和复盘记录 |
| F7 | 一键分享 | 复盘结果生成分享链接，他人免登录可查看，可随时关闭 |

### 不做（Out，第一版明确排除）

- ❌ 视频上传与 AI 视频分析（第二版做：视频时间轴定位，用 Warcraft Recorder 元数据）
- ❌ 团本分析（第二版以后）
- ❌ 跨多场 log 的综合成长分析（第二版）
- ❌ 模拟/配装、排名/分数、实时"按什么键"提示（永久不做——被 Raidbots/WCL/暴雪官方垄断）
- ❌ 录屏工具（永久不做——Archon App 官方已做）
- ❌ 移动端 App（网页自适应即可）
- ❌ 车队/多人协作复盘（远期）
- ❌ 代练/陪玩相关任何功能（合规红线）

## 成功指标（怎么算做成了，均为假设、上线后验证）

- **北极星指标**：每周完成 ≥1 次 AI 复盘的活跃用户数（反映"AI 复盘"这个核心价值有没有被用起来）。
- 支撑指标：
  - log 上传 → 完成复盘的转化率 ≥ 70%
  - 复盘完成后，7 天内再次上传的留存率 ≥ 20%
  - 完成复盘后主动发起提问的比例 ≥ 30%（验证"问答"价值）
  - 上线前 3 个月目标：注册用户 500、周活跃复盘用户 100

## 商业模式（初判，随阶段推进细化）

- 免费：基础 log 复盘（限次数）
- 订阅：AI 深度复盘/无限问答（对标 WCL Premium，约 $5–6/月级）
- 远期：高价一次性战术咨询
- 合规红线：只卖"自己的 AI 分析服务"，不卖暴雪游戏内容/视频；定位"自己进步"，远离代练陪玩。

## 已确认决策（阶段 2 需求澄清，用户拍板）

| 问题 | 决定 |
| --- | --- |
| log 上传方式 | 两者都要：WCL 链接优先，原生文件备用 |
| 对比顶尖玩家 | 第一版：玩家自己粘贴对比链接 |
| 问答范围 | 第一版：只针对当前这场 log |
| 账号 | 要注册登录（邮箱 + 验证码） |
| 一键分享 | 要做（分享链接免登录可查看，可随时关闭） |
| 免费额度 | 每天 3 次免费复盘，用尽提示订阅（订阅第一版仅展示，扣费第二版） |
